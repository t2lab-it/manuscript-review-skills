# R007：図表参照の役割と見る対象

図表がどの説明・比較・根拠に対応し、読者が何を見るかを追えるか点検する。
本文・図表・キャプションのうち、実際に読めた資料を根拠に判断する。
パネル、示す量、条件の対応も照合する。
食い違いは双方の位置と記述を示して質問し、本文とキャプションのどちらが正しいかを推測しない。

## 例

本文は「図4の結果から装置の精度が高い」とし、キャプションは「装置の外観写真」としている。

本文とキャプションの役割の違いを示し、精度の根拠にした資料を著者に確認する。
図の実体が未提供なら、画像内容は未確認として報告する。

本文が「図T(a)は加熱後の厚さ」、キャプションが「(a)加熱前の厚さ、(b)加熱後の質量」とする場合は、加熱条件と量の両方の対応を問う。
「(b)に直す」だけでは量の食い違いが残る。
読めた文章同士が一致していても、未提供の画像との一致は確認済みにしない。
