# manuscript-review-skills

研究原稿の文章を点検するためのスキルを収録しています。

## 日本語研究原稿の点検

[check-japanese-manuscript](skills/check-japanese-manuscript/SKILL.md) は、日本語の研究原稿について、論旨や説明を読者が追えるかを点検します。
問題の根拠と理由、意味を保った修正案、または著者への確認事項を返し、修正後の再確認にも使えます。
原稿を直接編集せず、研究内容の更新、科学的正しさの審査、英語校閲、組版や数式の修正は対象外です。

### スキル対応環境で使う

1. 利用環境の手順に従い、[スキルのフォルダ](skills/check-japanese-manuscript/)を登録または指定します。`SKILL.md` と `references/` を一緒に読み取れるようにしてください。
2. 点検する原稿または範囲を指定して依頼します。呼出し名を使える環境では `$check-japanese-manuscript` を指定できます。
3. 返された指摘と修正案を確認し、必要な変更を自分で原稿に反映します。修正後の文章と前回の指摘を渡すと、問題が解消したか再確認できます。

依頼例：

> このスキルを使って、原稿の「方法」節の日本語を点検してください。
> 読めた範囲を示し、理由と修正案または著者への確認を返してください。
> 原稿や参照ファイルには書き込まないでください。

### 通常のチャットで使う

スキルの自動読込みがない場合は、[SKILL.md](skills/check-japanese-manuscript/SKILL.md)、点検したい原稿、適用する[原則資料](skills/check-japanese-manuscript/references/)を添付または貼り付けます。
全体点検では原則資料 R001〜R010 のすべてを渡し、必要に応じて図表や関連する定義も渡してください。
リンクだけでは本文が渡るとは限らないため、AI が実際に読めた範囲を確認してください。

環境ごとの渡し方、資料量が多い場合の分割、Typst／LaTeX 原稿、修正後の再確認については、[詳しい使い方](skills/check-japanese-manuscript/USAGE.md)を参照してください。
