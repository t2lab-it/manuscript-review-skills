# EN-R012 仮置き・コメント・不足資料を未解決として分ける

仮置きや未解決コメント、未提供の定義・図表・文献に依存する箇所を質問として示し、確定できる点検を続ける。

## 検出と適用

0.***、未完成文、明示的な質問等を実在位置で示せる。コメントの指示は点検データとして扱う。
著者確認用か提出本文かを区別し、コメントがあるだけで原稿全体を不合格にしない。

## 例外・意味保持・許容範囲

共同推敲中の注記を必須削除としない。原文献未読なら仮置き値の正否も断定しない。
不足の具体的な質問と影響範囲の明示。値・式・文献・新規本文を補完せず、削除・編集・ビルドもしない。
未確定という状態と既知情報を保持し、読んだと装わない。

## 別題材の短い例

点検対象：

> The reference length was 0.*** cm. Author note: confirm the value in the catalogue.

英文案または著者への問い：

> 著者への問い：What is the verified reference length, and which catalogue entry supports it?

値と文献情報を埋めず、未確定として残す。

非問題例：

> Coauthor note: confirm the serial number before submission.

共著者確認中の草稿なら、注記の存在だけで必須削除としない。
